# Công cụ phát triển

> [English](README.md) | **Tiếng Việt**

---

## Các tập lệnh

- `validate_spec.py` — Kiểm tra đặc tả OpenAPI
- `check_endpoints.py` — Xác minh tất cả endpoint đã được triển khai
- `run_tests.sh` — Chạy kiểm thử cho tất cả SDK ngôn ngữ

## Cách dùng

```bash
python3 tools/validate_spec.py
python3 tools/check_endpoints.py
bash tools/run_tests.sh
```
